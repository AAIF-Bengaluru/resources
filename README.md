## Getting started with agentic AI

**AAIF projects**

- [Model Context Protocol (MCP)](https://modelcontextprotocol.io): connects LLM apps to data and tools.
- [AGENTS.md](https://agents.md): an open format for guiding coding agents.
- [Agent Skills](https://agentskills.io): an open format for packaging agent expertise.
- [A2A](https://a2a-protocol.org): lets agents talk and exchange tasks.
- [agentgateway](https://agentgateway.dev): connects agents, models, tools and APIs.
- [goose](https://goose-docs.ai): an extensible, open source AI agent.
- All projects, including Agent Router, Open Responses, OpenEnv and OpenSandbox: [github.com/aaif](https://github.com/aaif)

**Explore and learn**

- [AAIF Landscape](https://landscape.aaif.io): a map of the agentic AI ecosystem.
- [Model Context Protocol Associate (MCPA)](https://training.linuxfoundation.org/certification/model-context-protocol-associate-mcpa/): a beginner Linux Foundation certification on MCP.
- [AAIF events](https://aaif.io/events): AGNTCon + MCPCon, MCP Dev Summits and community meetups worldwide.

**Stay in touch**

- Bengaluru chapter: [Luma](https://luma.com/aaif-bengaluru) for events, and to reach the organizers.
- AAIF: [Discord](https://discord.aaif.io) · [LinkedIn](https://www.linkedin.com/company/agentic-ai-foundation) · [X](https://x.com/AgenticAIFdn) · [YouTube](https://www.youtube.com/@AgenticAI-Foundation)
